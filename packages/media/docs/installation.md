1. Install **LYNX** first (LYNX Media only imports files; LYNX assigns them to entries).
2. Install **LYNX Media** and approve its capabilities: network requests and writing to the media
   library.
3. For AI agents: Plugins → LYNX Media → switch **Agent access** on, and add the scope
   `mcp:tools:lynx-media` to the agent's API token.
