# @realmag777/lynx-engine

The shared engine of [LYNX](https://github.com/realmag777/lynx-emdash) for EmDash: the filter
grammar, bulk operations with validation, planning, history records and readable summaries.
Used by the LYNX core and LYNX Grid; it has no EmDash dependency of its own.

Made by Rostislav Sofronov (realmag777) — [realmag777.com](https://realmag777.com). MIT licence.
