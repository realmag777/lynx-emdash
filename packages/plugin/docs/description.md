LYNX turns an EmDash site with structured content (cars, properties, products, listings) into
something you can manage in bulk, by hand or with an AI agent.

- **Bulk edits with a preview**: pick entries with a filter, see before → after for a sample, apply,
  and roll back in one click. Text, numbers (percentages, rounding, price endings), choices, dates,
  taxonomy terms, status, duplicate and trash.
- **One history for everyone**: grid saves, bulk edits and AI-agent changes land in the same jobs.
  Every job can be rolled back; entries changed since are left alone.
- **AI agents (MCP)**: 17 tools with one working order (fields → find → preview → apply → rollback).
  The agent must show the count and the preview before it changes anything.
- **Safe on Cloudflare**: jobs run in small steps within the platform limits and resume by
  themselves.
- **LYNX Grid** (npm package `@realmag777/lynx-grid`): a spreadsheet page in the admin with cell editing,
  copy and paste, filters, saved views, keyboard shortcuts, light and dark themes.
- **LYNX Media** (separate plugin): images by URL for agents and the grid.

No network access, no tracking. Your content stays in your EmDash database.
