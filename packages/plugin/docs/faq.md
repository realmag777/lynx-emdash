**Can I undo a bulk edit?** Yes. History → Roll back restores every entry's previous values.
Entries someone changed after the job are left alone and listed.

**Does an AI agent change things without asking?** The agent must preview first and repeat the
exact count to apply. Every change it makes is in the history, marked as an agent change.

**Drafts or live?** On collections with revisions you choose: save as drafts (publish later) or
publish right away. Entries that carry someone else's draft are held back when publishing.

**What are "empty drafts"?** Rolling back a job saved as drafts leaves drafts equal to the
published version. The grid finds them and removes them for you.

**How many entries?** Up to 50,000 per selection. Jobs run in steps and continue by themselves.

**Why does agent access switch off after an update?** EmDash asks you to review plugin tools
again after every update. Switch it back on in Plugins → LYNX.
